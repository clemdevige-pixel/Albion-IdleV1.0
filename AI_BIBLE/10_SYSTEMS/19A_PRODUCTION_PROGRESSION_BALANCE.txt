# 19A. PRODUCTION PROGRESSION BALANCE

Status: AUTHORITATIVE BALANCE CONTRACT
Date: 2026-08-22

---

# Purpose

This document defines the production progression contract for Player Island levels, Gathering Mastery, Workers, standard production buildings and Silver/material sinks.

The Player Island is the single infrastructure authority for production tier access.

Standard gathering, refining and crafting buildings are permanent services constructed once. They do not level from T3 to T8 individually.

Special-purpose buildings may retain authored levels when those levels unlock meaningful capabilities. The Academy remains independently upgradeable.

---

# Gathering Mastery Tier Gates

Hero active gathering and Worker gathering use the same tier requirement.

T3: mastery 0
T4: mastery 3
T5: mastery 7
T6: mastery 11
T7: mastery 18
T8: mastery 25

Workers continue to grant Hero gathering mastery XP on completed cycles.

# Island Production Tier Authority

The Player Island level defines the maximum production tier available to every constructed standard production building.

Island Level 1 -> production through T3
Island Level 2 -> production through T4
Island Level 3 -> production through T5
Island Level 4 -> production through T6
Island Level 5 -> production through T7
Island Level 6 -> production through T8

This applies to:
- Lumber Camp
- Mine
- Hunting Camp
- Fiber Camp
- Sawmill
- Smelter
- Tannery
- Weaver
- Workshop

These buildings are construction-only in the current production contract.

They do not require separate tier upgrades after construction.

# Island Level / World Gates

Each island tier transition remains gated by world progression.

Island 2 / T4 -> after Dark Swamp T3
Island 3 / T5 -> after Frostpeak Mountain T4
Island 4 / T6 -> after Ironveil Peaks T5
Island 5 / T7 -> after Ashenpeak Mountain T6
Island 6 / T8 -> after Doompeak Mountain T7

Island Level 6 is therefore the infrastructure gate that enables T8 production.

# Centralized Island Upgrade Material Curve

Because standard production buildings no longer consume individual upgrade costs, the island upgrade itself carries the shared infrastructure material sink.

Every island upgrade requires all four refined resource families from the source tier in equal quantities:

- refined Wood
- refined Ore / Metal
- refined Hide / Leather
- refined Fiber / Cloth

Validated curve:

T3 -> T4 / Island 1 -> 2:
8 refined T3 of each family = 32 total

T4 -> T5 / Island 2 -> 3:
20 refined T4 of each family = 80 total

T5 -> T6 / Island 3 -> 4:
40 refined T5 of each family = 160 total

T6 -> T7 / Island 4 -> 5:
60 refined T6 of each family = 240 total

T7 -> T8 / Island 5 -> 6:
90 refined T7 of each family = 360 total

No family may substitute for another.

The equal four-family requirement prevents Wood/Ore-only bottlenecks and makes the island upgrade represent the whole production network.

# Centralized Island Silver Sink

Silver remains a secondary progression sink. It must matter without recreating the former repetitive tax of upgrading nine standard production buildings independently.

Validated island Silver curve:

T3 -> T4: 2,000 Silver
T4 -> T5: 30,000 Silver
T5 -> T6: 100,000 Silver
T6 -> T7: 265,000 Silver
T7 -> T8: 450,000 Silver

This replaces the former Player Island + 8 mono-family building + Workshop Silver distribution.

The Academy remains a separate Silver/material sink because its levels unlock actual research content rather than duplicating production-tier access.

Reference average best-farm Silver/hour from the previous calibration remains useful as a pacing reference:
- T3.0 transition: ~23.3k/h
- T4.3 transition: ~54.3k/h
- T5.3 transition: ~88.5k/h
- T6.3 transition: ~116.9k/h
- T7.3 transition: ~135.5k/h

Approximate dedicated Silver farm time represented by the new island-only curve at those reference rates:
- T3 -> T4: ~0.09 h
- T4 -> T5: ~0.55 h
- T5 -> T6: ~1.13 h
- T6 -> T7: ~2.27 h
- T7 -> T8: ~3.32 h

These are references, not mandatory dedicated grind sessions. Silver earned naturally during combat progression contributes to the same wallet.

# Academy Separation

The Academy is not part of the standard production-building tier progression.

It retains authored building levels because each level increases the available research tier and unlocks meaningful research content.

Academy upgrade costs remain defined independently from island production costs.

packages/data/src/config/academy-progression.ts

# Worker Contract

One Worker may operate each supported gathering family under the current Worker House capacity of 4.

Worker production may target T3-T8 when:

1. the Player Island supports that production tier,
2. the Worker's mastery meets the gathering mastery tier requirement,
3. the resource/refining content exists for that tier.

Worker cycles continue to provide:
- Worker mastery XP,
- Hero gathering mastery XP,
- raw resources into Shared Storage.

Hero gathering and Worker gathering remain parallel progression paths.

---

# Migration Rule

Legacy saved levels on standard gathering, refining and Workshop buildings no longer represent production progression.

When old saves are loaded, those standard buildings are normalized to level 1 while the Player Island level remains authoritative for production tier access.

Special-purpose authored progression such as the Academy remains preserved.

packages/gameplay/src/island/island-service.ts

---

# Design Rules

Rule 01
Player Island level is the single authority for standard production tier access.

Rule 02
Gathering, refining and Workshop buildings are constructed once and do not level merely to unlock the next production tier.

Rule 03
Building levels are reserved for meaningful functional progression, not duplicate tier gates.

Rule 04
Every island tier upgrade requires all four refined production families in equal quantities.

Rule 05
T8 production requires Player Island Level 6.

Rule 06
Silver is a meaningful secondary sink but must not recreate the former multi-building upgrade tax.

Rule 07
The Academy remains independently upgradeable because its levels unlock research content.

Rule 08
Gathering mastery gates remain 0 / 3 / 7 / 11 / 18 / 25 for T3-T8.

Rule 09
Balance values remain data driven. UI and runtime logic consume the same authored definitions.
