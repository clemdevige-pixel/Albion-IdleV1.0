# ARMOR DATABASE

Version: 1.0

This document defines every wearable armor item available in Version 1.

Each armor entry references the corresponding visual asset defined in
**41_ASSET_MANIFEST.md**.

Numerical values are not stored in this document.

Armor statistics, crafting costs and progression values are inherited from
the profiles referenced by each entry.

---

# ============================================================================
# DATABASE RULES
# ============================================================================

Armor ID:
Permanent gameplay identifier.

Asset ID:
Identifier of the equipped armor sprite or model.

Icon ID:
Identifier of the inventory and interface icon.

Scaling Profile:
Defines health, armor, magic resistance and movement modifiers.

Craft Profile:
Defines required resources, crafting time and crafting cost.

Ability Profile:
Defines the active or passive ability granted by the armor item.

All armor variants inherit the same base entry.

Generated item identifiers follow this format:

ARM-0001-T2
ARM-0001-T3
ARM-0001-T4
ARM-0001-T5
ARM-0001-T6
ARM-0001-T7
ARM-0001-T8

Generated asset identifiers follow the same format.

Example:

Gameplay Item:
ARM-0001-T6

Equipped Asset:
ARM-0001-T6

Inventory Icon:
ICO-ARM-0001-T6

Display Name:
Cloth Hood T6

# ============================================================================
# GENERATION RULES
# ============================================================================

Every base armor item generates seven tier variants.

Generated Tiers:
- T2
- T3
- T4
- T5
- T6
- T7
- T8

The base ID never changes.

Example:

Base Armor:
ARM-0008

Generated Variants:
- ARM-0008-T2
- ARM-0008-T3
- ARM-0008-T4
- ARM-0008-T5
- ARM-0008-T6
- ARM-0008-T7
- ARM-0008-T8

Each generated variant receives:

- The same armor name
- The same armor type
- The same equipment slot
- The same combat role
- The same ability profile
- The tier-specific visual asset
- The tier-specific inventory icon
- Statistics generated from its scaling profile
- A recipe generated from its crafting profile
- A value generated from the economy rules
- A repair cost generated from the repair rules

No generated system may modify:

- Armor ID
- Armor name
- Armor type
- Equipment slot
- Asset reference
- Icon reference
- Ability profile
- Crafting profile
- Scaling profile
