# MONSTER DATABASE

Version: 1.0

This document defines every hostile creature available in Version 1.

Each monster references the corresponding visual asset defined in
**41_ASSET_MANIFEST.md**.

Numerical values are not stored in this document.

Monster statistics, loot, AI and progression values are inherited from the
profiles referenced by each entry.

---

# ============================================================================
# DATABASE RULES
# ============================================================================

Monster ID:
Permanent gameplay identifier.

Asset ID:
Identifier of the monster sprite.

Portrait ID:
Reserved for future use.

Scaling Profile:
Defines HP, Damage, Armor, Resistances and Experience.

Loot Profile:
Defines every possible loot drop.

AI Profile:
Defines behaviour.

Spawn Profile:
Defines where the monster may appear.

Faction:
Defines relationship with other monsters.

Generated identifiers follow this format:

MON-0001-T2
MON-0001-T3
MON-0001-T4
MON-0001-T5
MON-0001-T6
MON-0001-T7
MON-0001-T8

# ============================================================================
# GENERATION RULES
# ============================================================================

Every monster automatically generates Tier variants according to its Spawn
Profile.

Each generated monster inherits:

- Name
- Asset
- AI
- Loot Profile
- Behaviour
- Animations
- Faction

Only the following values are generated procedurally:

- HP
- Damage
- Armor
- Magic Resistance
- Silver Reward
- Fame / Experience
- Loot Quantity
- Loot Quality

No generated system may modify:

- Monster ID
- Name
- Asset ID
- Faction
- AI Profile
- Loot Profile
- Spawn Profile
