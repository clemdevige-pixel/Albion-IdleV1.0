# OFF-HAND DATABASE

Version: 1.0

This document defines every equippable off-hand item available in Version 1.

Each off-hand entry references the corresponding visual asset defined in
**41_ASSET_MANIFEST.md**.

Numerical values are not stored in this document.

Off-hand statistics, crafting costs and progression values are inherited from
the profiles referenced by each entry.

---

# ============================================================================
# DATABASE RULES
# ============================================================================

Off-Hand ID:
Permanent gameplay identifier.

Asset ID:
Identifier of the equipped off-hand sprite or model.

Icon ID:
Identifier of the inventory and interface icon.

Scaling Profile:
Defines the numerical bonuses granted by the off-hand.

Craft Profile:
Defines required resources, crafting time and crafting cost.

Passive Profile:
Defines the permanent passive effect granted while equipped.

All off-hand variants inherit the same base entry.

Generated item identifiers follow this format:

OFF-0001-T4
OFF-0001-T5
OFF-0001-T6
OFF-0001-T7
OFF-0001-T8

Generated asset identifiers follow the same format.

Example:

Gameplay Item:
OFF-0001-T6

Equipped Asset:
OFF-0001-T6

Inventory Icon:
ICO-OFF-0001-T6

Display Name:
Knight Shield T6

# ============================================================================
# EQUIPMENT COMPATIBILITY RULES
# ============================================================================

Off-hand items may only be equipped with one-handed weapons.

Compatible Weapon Handed Types:

- One-Handed

Incompatible Weapon Handed Types:

- Two-Handed
- Dual-Wield

When a two-handed or dual-wield weapon is equipped, the off-hand slot is
automatically disabled.

When a one-handed weapon is equipped, the player may equip one valid off-hand
item.

An off-hand item cannot be equipped without a main-hand weapon.

The equipment system must validate compatibility before applying any off-hand
statistics or passive effects.

# ============================================================================
# GENERATION RULES
# ============================================================================

Every base off-hand item generates five tier variants.

Generated Tiers:
- T4
- T5
- T6
- T7
- T8

The base ID never changes.

Example:

Base Off-Hand:
OFF-0001

Generated Variants:
- OFF-0001-T4
- OFF-0001-T5
- OFF-0001-T6
- OFF-0001-T7
- OFF-0001-T8

Each generated variant receives:

- The same off-hand name
- The same off-hand type
- The same equipment slot
- The same combat role
- The same compatibility rules
- The same passive profile
- The tier-specific visual asset
- The tier-specific inventory icon
- Statistics generated from its scaling profile
- A recipe generated from its crafting profile
- A value generated from the economy rules
- A repair cost generated from the repair rules

No generated system may modify:

- Off-hand ID
- Off-hand name
- Off-hand type
- Equipment slot
- Asset reference
- Icon reference
- Passive profile
- Crafting profile
- Scaling profile
- Weapon compatibility
