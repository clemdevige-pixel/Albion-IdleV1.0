# WEAPON DATABASE

Version: 1.0

This document defines every playable weapon available in Version 1.

Each weapon references the corresponding visual asset defined in
**41_ASSET_MANIFEST.md**.

Numerical values are not stored in this document.

Weapon statistics, crafting costs and progression values are inherited from
the profiles referenced by each entry.

---

# ============================================================================
# DATABASE RULES
# ============================================================================

Weapon ID:
Permanent gameplay identifier.

Asset ID:
Identifier of the equipped weapon sprite or model.

Icon ID:
Identifier of the inventory and interface icon.

Scaling Profile:
Defines damage, attack speed, range and other numerical statistics.

Craft Profile:
Defines required resources, crafting time and crafting cost.

Ability Profile:
Defines the abilities available while the weapon is equipped.

All Tier 4 to Tier 8 variants inherit the same base weapon entry.

Generated item identifiers follow this format:

WPN-0001-T4
WPN-0001-T5
WPN-0001-T6
WPN-0001-T7
WPN-0001-T8

Generated asset identifiers follow the same format.

Example:

Gameplay Item:
WPN-0001-T6

Equipped Asset:
WPN-0001-T6

Inventory Icon:
ICO-WPN-0001-T6

Display Name:
Broadsword T6

# ============================================================================
# GENERATION RULES
# ============================================================================

Every base weapon generates five tier variants.

Generated Tiers:
- T4
- T5
- T6
- T7
- T8

The base ID never changes.

Example:

Base Weapon:
WPN-0001

Generated Variants:
- WPN-0001-T4
- WPN-0001-T5
- WPN-0001-T6
- WPN-0001-T7
- WPN-0001-T8

Each generated variant receives:

- The same weapon name
- The same weapon family
- The same handed type
- The same combat role
- The same ability profile
- The tier-specific visual asset
- The tier-specific inventory icon
- Statistics generated from its scaling profile
- A recipe generated from its crafting profile
- A value generated from the economy rules
- A repair cost generated from the repair rules

No generated system may modify:

- Weapon ID
- Weapon name
- Weapon family
- Asset reference
- Icon reference
- Ability profile
- Crafting profile
- Scaling profile
