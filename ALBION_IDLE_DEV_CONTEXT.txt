9) WEAPON PIPELINE STEP 6 — RETIRE STALE content/data WEAPON RECORDS
Date/session: 2026-08-10
Status: implementation pushed; Vercel/data-validation check pending.

Audit findings:
- content/data/*.json are not loaded by the active client weapon runtime.
- repository search found content/data consumption in the generic @game/data/tooling validation architecture, not in active weapon gameplay.
- packages/tooling/src/validate-data.ts scans every JSON in content/data and validates envelope/schema only.
- weapon records in items.json/equipment.json/recipes.json were stale parallel authoring sources and contradicted live runtime values/rules.
Examples found before removal:
  - equipment.json Broadsword T4 = 128 physical / 1.1 attack speed, unlike live catalog.
  - items.json Spiked T3 supported enchantments, contradicting current V1 T4 minimum.
  - recipes.json T4 standard weapon recipes did not encode the live T(n-1) predecessor rule.

Decision:
Do NOT delete content/data or @game/data architecture: it remains a generic data-runtime/tooling foundation and contains non-weapon content.
Instead remove only stale weapon records so there is no second weapon authoring source.

Files modified:
- content/data/items.json
- content/data/equipment.json
- content/data/recipes.json
- ALBION_IDLE_DEV_CONTEXT.txt

Changes:
- removed all weapon item records from items.json.
- removed all weapon equipment records from equipment.json.
- removed all weapon crafting recipes from recipes.json.
- retained unrelated armor/resource/consumable/refining/cooking records unchanged.
- no active runtime weapon behavior is intentionally changed.

Resulting authority:
- weapon gameplay identity/stats/masteries/abilities/craft rules: weaponContentCatalog.ts.
- generated live equipment recognition: itemContentCatalog.ts.
- generated live standard recipes: refiningRecipes.ts.
- specialization presentation: equipmentPresentation.ts.
- actual renderer/projectile manifests remain explicit presentation content.
- content/data no longer claims to be a second source for weapon content.
